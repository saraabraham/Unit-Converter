# 🌡️ Metric / Imperial Unit Converter

A simple and elegant web app that converts between **metric** and **imperial** units — including **length**, **volume**, and **mass**.

🔗 **Live Demo:** [Unit Converter](https://saraabraham.github.io/Unit-Converter/)

---

## 🛠️ Features

- 🔹 Convert **Length** — meters ↔ feet  
- 🔹 Convert **Volume** — liters ↔ gallons  
- 🔹 Convert **Mass** — kilograms ↔ pounds  
- 🔹 Real-time conversion (auto-updates as you type)  
- 🔹 Clean, minimal UI  
- 🔹 Fully responsive — works on desktop & mobile

---


---

## 🚀 How to Use

1. Open the app in your browser.  
2. Enter any numeric value in the input field.  
3. View instant conversions for:  
   - Meters ⇄ Feet  
   - Liters ⇄ Gallons  
   - Kilograms ⇄ Pounds  

### 📏 Example Conversions

| Metric Unit | Imperial Equivalent |
|--------------|--------------------|
| 1 meter      | ≈ 3.28084 feet     |
| 1 liter      | ≈ 0.264172 gallons |
| 1 kilogram   | ≈ 2.20462 pounds   |
